# Auto Fishing Macro

Automate fishing in NTE by controlling the keyboard via screen recognition.

## 실행

You can run [NTE-auto-fish.exe](https://github.com/godxxy1229/NTE-auto-fish/releases/download/v0.0.1/NTE-auto-fish.exe).

or

```powershell
python -m pip install -r requirements.txt
python main.py
```
